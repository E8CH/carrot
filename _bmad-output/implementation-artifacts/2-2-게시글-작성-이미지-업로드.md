# Story 2.2: 게시글 작성 & 이미지 업로드

Status: done

## Story

As a 로그인한 판매자,
I want to create a post with photos, title, description, price, and trade location,
so that buyers can find and contact me about my item.

## Acceptance Criteria

1. `POST /api/v1/posts/upload-url`을 호출하면 Supabase Storage Presigned URL이 반환된다 (JWT 필요)
2. Presigned URL로 이미지를 직접 업로드한 후 `POST /api/v1/posts`를 호출하면 게시글이 `status: 판매중`으로 생성된다
3. 사진이 1장 미만(`photos=[]`)이면 `{"detail": "사진을 1장 이상 업로드해야 합니다.", "code": "PHOTO_REQUIRED"}` 에러가 반환된다
4. Next.js `/posts/new`에서 5MB 초과 이미지 선택 시 즉시 에러 표시 및 선택 거부
5. Next.js 작성 완료 후 "등록됐어요!" 토스트와 함께 홈 피드(`/`)로 이동
6. Flutter FAB 탭 시 갤러리 권한 요청 후 사진 선택, 동일한 Presigned URL 업로드 흐름 적용

## Dev Notes

### Presigned URL 흐름 (AR-5, NFR-2)

```
1. 클라이언트 → FastAPI: POST /api/v1/posts/upload-url  (JWT)
2. FastAPI → Supabase Storage: presigned URL 발급 (SDK)
3. FastAPI → 클라이언트: {upload_url, file_path}
4. 클라이언트 → Supabase Storage: PUT upload_url (Content-Type: image/*)
5. 클라이언트: 공개 URL = SUPABASE_URL/storage/v1/object/public/posts/{file_path}
6. 클라이언트 → FastAPI: POST /api/v1/posts {photos: [공개URL, ...]}
```

### carrot-api: Supabase Storage SDK 사용

```python
# app/features/posts/router.py
from supabase import create_client
from app.core.config import settings
import uuid

supabase = create_client(settings.SUPABASE_URL, settings.SUPABASE_KEY)

@router.post("/upload-url", response_model=UploadUrlResponse)
async def get_upload_url(current_user: dict = Depends(get_current_user)) -> UploadUrlResponse:
    seller_email = current_user.get("sub", "unknown")
    file_path = f"{seller_email}/{uuid.uuid4()}.jpg"
    # Supabase Storage signed URL (60초 유효)
    response = supabase.storage.from_("posts").create_signed_upload_url(file_path)
    return UploadUrlResponse(
        upload_url=response["signedURL"],
        file_path=file_path,
    )
```

> ⚠️ Supabase Storage bucket "posts"가 미리 생성되어 있어야 함. 없으면 404.  
> 개발 시 Supabase 대시보드에서 "posts" bucket 생성 + public 설정 필요.

### carrot-web: 5MB 검증 + Presigned URL 업로드

```typescript
const MAX_SIZE = 5 * 1024 * 1024  // 5MB

const handleFileSelect = (e: React.ChangeEvent<HTMLInputElement>) => {
  const files = Array.from(e.target.files ?? [])
  const oversized = files.filter(f => f.size > MAX_SIZE)
  if (oversized.length) {
    setError(`5MB를 초과하는 파일이 있습니다: ${oversized.map(f => f.name).join(', ')}`)
    e.target.value = ''  // 선택 초기화
    return
  }
  setSelectedFiles(files)
}

const uploadFile = async (file: File): Promise<string> => {
  const { upload_url, file_path } = await postsApi.getUploadUrl()
  await fetch(upload_url, {
    method: 'PUT',
    body: file,
    headers: { 'Content-Type': file.type || 'image/jpeg' },
  })
  return `${process.env.NEXT_PUBLIC_SUPABASE_URL}/storage/v1/object/public/posts/${file_path}`
}
```

Future<void> _pickImages() async {

  const maxBytes = 5 * 1024 * 1024;

  for (final img in picked.take(10)) {
    final bytes = await img.readAsBytes();
