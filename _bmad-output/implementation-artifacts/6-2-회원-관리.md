# Story 6.2: 회원 관리

Status: done

## Story

As a 관리자,
I want to view all users and activate or deactivate their accounts,
so that I can control access and handle problematic users.

## Acceptance Criteria

1. 관리자가 `GET /api/v1/admin/users`를 호출하면 전체 회원 목록이 `{items: [...], total: N}` 형식으로 반환된다
2. 각 항목에 `email, created_at, manner_temp, post_count, is_active`가 포함된다
3. 관리자가 `PATCH /api/v1/admin/users/{email}/status`를 호출하면 (`{is_active: bool}`) 해당 회원의 `is_active`가 변경된다
4. 비관리자 JWT로 이 엔드포인트들을 호출하면 `ADMIN_REQUIRED` 403이 반환된다
5. carrot-admin 회원 관리 페이지에서 테이블로 회원 목록이 표시된다 (email, 가입일, 매너온도, 게시글 수, 활성화 상태)
6. 각 행에 활성화/비활성화 버튼이 표시되고, 클릭 시 즉시 토스트 메시지가 표시된다

### Task 2: users/repository.py get_all_users

Post 모델은 `app.features.posts.models` — 이미 repository.py에서 사용 중. 추가 import 불필요.

```python
async def get_all_users(db: AsyncSession) -> tuple[list, int]:
    from app.features.posts.models import Post  # circular import 방지를 위해 local import
    post_count_sq = (
        select(func.count(Post.id))
        .where(Post.seller_email == User.email, Post.is_draft == False)  # noqa: E712
        .correlate(User)
        .scalar_subquery()
    )
    stmt = (
        select(User, post_count_sq.label("post_count"))
        .order_by(User.created_at.desc())
    )
    rows = (await db.execute(stmt)).all()
    return rows, len(rows)
```

**순환 import 주의**: `users/repository.py`는 이미 `app.features.posts.models`을 import하지 않음. `app.features.posts.models`가 `users`를 import할 수도 있으므로 local import 사용.

실제로 현재 `users/repository.py`에는 `from app.features.posts.models import Like, Post`가 없음. 하지만 `posts/repository.py`에는 `from app.features.users.models import User`가 있음. 이 방향의 순환은 없으므로 상단에 직접 import 가능.

**대안 (더 안전)**: `admin/router.py`에서 직접 쿼리 작성, 또는 `admin/repository.py` 신규 생성.

→ `admin/repository.py`를 신규 생성하여 admin 전용 쿼리를 분리:

```python
# carrot-api/app/features/admin/repository.py
from sqlalchemy import func, select
from sqlalchemy.ext.asyncio import AsyncSession

from app.features.posts.models import Post
from app.features.users.models import User


async def get_all_users(db: AsyncSession) -> tuple[list, int]:
    post_count_sq = (
        select(func.count(Post.id))
        .where(Post.seller_email == User.email, Post.is_draft == False)  # noqa: E712
        .correlate(User)
        .scalar_subquery()
    )
    stmt = (
        select(User, post_count_sq.label("post_count"))
        .order_by(User.created_at.desc())
    )
    rows = (await db.execute(stmt)).all()
    return rows, len(rows)
```

### Task 3: admin/router.py 수정

`require_admin`은 `app.core.dependencies`에 이미 존재. 기존 `router.py`에 추가:

```python
from app.core.dependencies import require_admin
from app.features.admin import repository as admin_repo
from app.features.admin.schemas import AdminUsersResponse, AdminUserStatusRequest

@router.get("/users", response_model=AdminUsersResponse)
async def get_admin_users(
    _: dict = Depends(require_admin),
    db: AsyncSession = Depends(get_db),
) -> AdminUsersResponse:
    rows, total = await admin_repo.get_all_users(db)
    items = [
        AdminUserItem(
            email=user.email,
            created_at=user.created_at,
            manner_temp=user.manner_temp,
            post_count=post_count,
            is_active=user.is_active,
        )
        for user, post_count in rows
    ]
    return AdminUsersResponse(items=items, total=total)

@router.patch("/users/{email}/status", response_model=AdminUserItem)
async def update_user_status(
    email: str,
    request: AdminUserStatusRequest,
    _: dict = Depends(require_admin),
    db: AsyncSession = Depends(get_db),
) -> AdminUserItem:
    user = await users_repo.get_user_by_email(db, email)
    if not user:
        raise AppException(code="USER_NOT_FOUND", detail="사용자를 찾을 수 없습니다.", status_code=404)
    user.is_active = request.is_active
    await db.commit()
    await db.refresh(user)
    return AdminUserItem(
        email=user.email,
        created_at=user.created_at,
        manner_temp=user.manner_temp,
        post_count=0,  # 상태 변경 응답에서는 count 불필요
        is_active=user.is_active,
    )
```

**기존 router.py 보존**: 기존 `admin_register`, `admin_login` 유지.

### Task 5: admin-users.ts

```typescript
import apiClient from './axios'

export interface AdminUserItem {
  email: string
  created_at: string
  manner_temp: number
  post_count: number
  is_active: boolean
}

export interface AdminUsersResponse {
  items: AdminUserItem[]
  total: number
}

export const adminUsersApi = {
  getUsers: (): Promise<AdminUsersResponse> =>
    apiClient.get<AdminUsersResponse>('/api/v1/admin/users').then((r) => r.data),

  updateStatus: (email: string, isActive: boolean): Promise<AdminUserItem> =>
    apiClient
      .patch<AdminUserItem>(`/api/v1/admin/users/${encodeURIComponent(email)}/status`, { is_active: isActive })
      .then((r) => r.data),
}
```

**`encodeURIComponent(email)`**: email에 `@`가 포함되어 URL 인코딩 필수.
