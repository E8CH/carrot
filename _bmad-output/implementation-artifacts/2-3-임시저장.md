# Story 2.3: 임시저장

Status: done

## Story

As a 로그인한 판매자,
I want to save my post draft and resume editing later,
so that I don't lose my work if I need to stop mid-way.

## Acceptance Criteria

1. 로그인한 회원이 게시글 작성 중 "임시저장" 버튼을 탭하면 `POST /api/v1/posts/draft`를 호출하여 현재 입력 내용이 저장된다 (계정당 1개, 기존 임시저장이 있으면 덮어씀)
2. 임시저장된 게시글은 `GET /api/v1/posts` 목록에 포함되지 않는다
3. 임시저장이 있는 회원이 게시글 작성 화면을 열면 "이전에 작성 중인 글이 있어요. 이어서 작성하시겠어요?" 안내가 표시되고 확인 시 내용이 복원된다
4. Next.js 게시글 작성 화면에서 "← 뒤로" 버튼 탭 시 "임시저장할까요?" 다이얼로그가 표시된다
5. Flutter 게시글 작성 화면에서 뒤로가기(팝) 시 "임시저장할까요?" 다이얼로그가 표시된다

class SaveDraftRequest(BaseModel):
    title: str = Field(default="", max_length=100)
    description: str = Field(default="")
    price: int | None = Field(default=None, ge=0)
    is_free: bool = False
    trade_place: str | None = None
    photos: list[str] = Field(default_factory=list, max_length=10)

    @model_validator(mode="after")
    def price_none_when_free(self) -> "SaveDraftRequest":
        if self.is_free and self.price is not None:
            raise ValueError("나눔 게시글은 price를 설정할 수 없습니다.")
        return self


class DraftResponse(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    title: str
    description: str
    price: int | None
    is_free: bool
    trade_place: str | None
    photos: list[str]
    updated_at: datetime

### carrot-api: Repository upsert 패턴

```python
# app/features/posts/repository.py 추가

async def get_draft(db: AsyncSession, seller_email: str) -> Post | None:
    stmt = (
        select(Post)
        .where(Post.seller_email == seller_email, Post.is_draft == True)  # noqa: E712
        .limit(1)
    )
    return (await db.execute(stmt)).scalar_one_or_none()


async def upsert_draft(
    db: AsyncSession,
    *,
    seller_email: str,
    request: "SaveDraftRequest",
) -> Post:
    existing = await get_draft(db, seller_email)
    if existing:
        existing.title = request.title
        existing.description = request.description
        existing.price = request.price
        existing.is_free = request.is_free
        existing.trade_place = request.trade_place
        existing.photos = request.photos
        post = existing
    else:
        post = Post(
            seller_email=seller_email,
            title=request.title,
            description=request.description,
            price=request.price,
            is_free=request.is_free,
            trade_place=request.trade_place,
            photos=request.photos,
            status="판매중",
            is_draft=True,
        )
        db.add(post)
    try:
        await db.commit()
        await db.refresh(post)
    except IntegrityError as e:
        await db.rollback()
        raise AppException(
            code="DRAFT_SAVE_FAILED",
            detail="임시저장에 실패했습니다.",
            status_code=422,
        ) from e
    return post
```

    db: AsyncSession = Depends(get_db),

    seller_email = current_user.get("sub")
    if not seller_email:
        raise AppException(code="UNAUTHORIZED", detail="유효하지 않은 토큰입니다.", status_code=401)

    if draft is None:
        raise AppException(code="DRAFT_NOT_FOUND", detail="임시저장 게시글이 없습니다.", status_code=404)
    return draft

    request: SaveDraftRequest,

    db: AsyncSession = Depends(get_db),

        raise AppException(code="UNAUTHORIZED", detail="유효하지 않은 토큰입니다.", status_code=401)

    final repo = PostsRepository(client);

      builder: (ctx) => AlertDialog(

        content: const Text('이어서 작성하시겠어요?'),

            child: Text('이어서 작성', style: TextStyle(color: AppColors.primary)),
          ),
        ],
      ),
    );

        _titleCtrl.text = draft['title'] as String? ?? '';
        _descCtrl.text = draft['description'] as String? ?? '';

      });
    }
  } catch (_) {
    // 네트워크 에러 등 — 무음 처리 (draft 로드 실패가 작성 화면 진입을 막으면 안 됨)

### carrot-mobile: getDraft()에서 404 처리

```dart
// posts_repository.dart 추가
Future<Map<String, dynamic>?> getDraft() async {
  try {
    final result = await _client.get(ApiEndpoints.postsDraft);
    return result as Map<String, dynamic>;
  } on Exception catch (e) {
    // 404는 "draft 없음"으로 처리, 다른 에러는 rethrow
    if (e.toString().contains('404')) return null;
    rethrow;
  }
}

Future<Map<String, dynamic>> saveDraft({
  required String title,
  required String description,
  int? price,
  bool isFree = false,
  String? tradePlace,
  List<String> photos = const [],
}) async {
  final result = await _client.post(
    ApiEndpoints.postsDraft,
    body: {
      'title': title,
      'description': description,
      'price': price,
      'is_free': isFree,
      'trade_place': tradePlace,
      'photos': photos,
    },
  );
  return result as Map<String, dynamic>;
}
```

> **ApiClient 404 처리**: ApiClient가 404를 Exception으로 throw하는지 확인 필요. `lib/core/api/api_client.dart`를 읽고 에러 처리 방식에 맞게 조정할 것. 만약 ApiClient가 status code를 포함한 custom exception을 던진다면 해당 타입으로 catch.
