# Story 4.1: 거래 상태 변경

Status: done

## Story

As a 판매자,
I want to update the status of my post between 판매중 and 예약중,
So that buyers can see the current availability of my item.

## Acceptance Criteria

1. 판매자 본인이 `PATCH /api/v1/posts/{post_id}/status`를 호출하면 (`{status: '예약중'|'판매중'}`) 게시글 상태가 변경되고 변경된 `PostDetailResponse`가 반환된다 (JWT 필요)
2. 타인이 상태 변경을 시도하면 `{"detail": "권한이 없습니다.", "code": "FORBIDDEN"}` 403 에러가 반환된다
3. Next.js 게시글 상세(isOwner)에서 상태 변경 버튼을 클릭하면 새 상태를 선택할 수 있고 즉시 StatusBadge에 반영된다
4. Flutter 게시글 상세(isOwner)에서 동일하게 동작한다

**스코프 제한**: `거래완료` 상태 변경은 Story 4.2 (`PATCH /{post_id}/complete`)에서 구현. 이 스토리는 `판매중` ↔ `예약중` 전환만 처리.

## Dev Notes

### carrot-api: PostStatusRequest

```python
from pydantic import BaseModel, model_validator

class PostStatusRequest(BaseModel):
    status: str

    @model_validator(mode='after')
    def validate_status(self) -> 'PostStatusRequest':
        if self.status not in ('판매중', '예약중'):
            raise ValueError("판매중 또는 예약중만 변경 가능합니다.")
        return self
```

`거래완료`는 허용 안 함 (Story 4.2의 별도 endpoint에서 처리).

### carrot-api: service.change_post_status

```python
async def change_post_status(
    db: AsyncSession,
    seller_email: str,
    post_id: int,
    new_status: str,
) -> PostDetailResponse:
    post = await _get_owned_post(db, post_id, seller_email)
    post.status = new_status
    try:
        await db.commit()
        await db.refresh(post)
    except IntegrityError as e:
        await db.rollback()
        raise AppException(code="STATUS_CHANGE_FAILED", detail="상태 변경에 실패했습니다.", status_code=422) from e
    return PostDetailResponse(
        id=post.id,
        seller_email=post.seller_email,
        title=post.title,
        description=post.description,
        price=post.price,
        is_free=post.is_free,
        status=post.status,
        trade_place=post.trade_place,
        photos=post.photos,
        view_count=post.view_count,
        created_at=post.created_at,
        updated_at=post.updated_at,
        chat_count=0,
        like_count=0,
        manner_temp=36.5,
        is_liked=False,
    )
```

`_get_owned_post` — 이미 service.py에 존재, 재사용.

**Import**: `PostStatusRequest` schema import 추가.

### carrot-api: router.PATCH /{post_id}/status

```python
@router.patch("/{post_id}/status", response_model=PostDetailResponse)
async def change_post_status(
    request: PostStatusRequest,
    post_id: int = Path(ge=1),
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
) -> PostDetailResponse:
    seller_email = current_user.get("sub")
    if not seller_email:
        raise AppException(code="UNAUTHORIZED", detail="유효하지 않은 토큰입니다.", status_code=401)
    return await service.change_post_status(db, seller_email, post_id, request.status)
```

`PATCH /{post_id}/status` vs `PATCH /{post_id}` — 세그먼트 수가 달라 충돌 없음 (2개 vs 1개).

### carrot-web: /posts/[id]/page.tsx 수정

```tsx
// 상태 변경 상태
const [statusLoading, setStatusLoading] = useState(false)

// TanStack Query client for invalidation
const queryClient = useQueryClient()

// handleStatusChange
const handleStatusChange = async (newStatus: string) => {
  if (statusLoading) return
  setStatusLoading(true)
  try {
    await postsApi.changeStatus(postId, newStatus)
    queryClient.invalidateQueries({ queryKey: ['post', postId] })
  } catch { /* 에러 무시 */ }
  finally { setStatusLoading(false) }
}
```

### carrot-mobile: post_detail_screen.dart

```dart
bool _statusLoading = false;

Future<void> _changeStatus(String newStatus) async {
  if (_statusLoading) return;
  if (mounted) setState(() => _statusLoading = true);
  try {
    final client = ref.read(apiClientProvider);
    final repo = PostsRepository(client);
    await repo.changeStatus(widget.postId, newStatus);
    await _loadPost();  // 새로고침
  } catch (_) {
    if (mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('상태 변경에 실패했습니다.')),
      );
    }
  } finally {
    if (mounted) setState(() => _statusLoading = false);
  }
}
```
