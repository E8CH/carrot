# Story 3.2: 메시지 전송 및 수신 (폴링)

Status: done

## Story

As a 채팅방 참여자,
I want to send messages and receive replies in near real-time,
So that I can communicate with the other party about the trade.

## Acceptance Criteria

1. 채팅방 참여자가 `POST /api/v1/chats/{room_id}/messages`로 메시지를 전송하면 메시지가 DB에 저장되고 저장된 메시지 데이터가 반환된다 (JWT 필요)
2. `GET /api/v1/chats/{room_id}/messages?after={last_message_id}`를 호출하면 last_message_id 이후의 신규 메시지 배열이 반환된다 (없으면 빈 배열). `after` 없이 호출하면 최근 50개가 반환된다
3. 클라이언트는 2500ms마다 폴링하여 SM-C1(1초 미만 금지)을 준수한다
4. Next.js 채팅방에서 메시지를 전송하면 낙관적 UI로 즉시 오른쪽 ChatBubble이 노출된다 ("전송 중" ⏳ 아이콘 표시)
5. Flutter 채팅방에서 메시지를 전송하면 낙관적 UI로 즉시 오른쪽 ChatBubble이 노출된다
6. 폴링으로 서버 확인 후 "전송 중" 아이콘이 제거된다 (서버 응답 메시지로 교체)
7. 전송 실패 시 ChatBubble에 에러 상태가 표시된다

## Dev Notes

### 핵심 설계 결정: room 메타데이터 없는 순수 메시지 기반

`chat_messages` 테이블에 별도 rooms 테이블이 없다. 각 메시지에 `seller_email`, `buyer_email`, `post_id`가 중복 저장된다 (비정규화). 첫 메시지 전송 시 이 정보가 최초 기록된다.

- 첫 메시지: `post_id`를 body로 전달 → 서버가 post에서 `seller_email` 추출, JWT에서 `buyer_email` 추론
- 이후 메시지: 기존 메시지에서 메타 추출 (post_id는 body 필요 없으나 호환성 위해 유지)

### carrot-api: repository.py 추가

```python
async def get_room_context(db: AsyncSession, room_id: str) -> "ChatMessage | None":
    stmt = (
        select(ChatMessage)
        .where(ChatMessage.room_id == room_id)
        .order_by(ChatMessage.sent_at)
        .limit(1)
    )
    return (await db.execute(stmt)).scalar_one_or_none()

async def create_message(
    db: AsyncSession,
    room_id: str,
    seller_email: str,
    buyer_email: str,
    post_id: int,
    message: str,
) -> ChatMessage:
    msg = ChatMessage(
        room_id=room_id,
        seller_email=seller_email,
        buyer_email=buyer_email,
        post_id=post_id,
        message=message,
        is_read=False,
    )
    db.add(msg)
    try:
        await db.commit()
        await db.refresh(msg)
    except IntegrityError as e:
        await db.rollback()
        raise AppException(code="MESSAGE_SEND_FAILED", detail="메시지 전송에 실패했습니다.", status_code=422) from e
    return msg

async def get_messages(
    db: AsyncSession,
    room_id: str,
    after_id: int | None = None,
    limit: int = 50,
) -> list[ChatMessage]:
    stmt = select(ChatMessage).where(ChatMessage.room_id == room_id)
    if after_id is not None:
        stmt = stmt.where(ChatMessage.id > after_id)
    stmt = stmt.order_by(ChatMessage.sent_at).limit(limit)
    return list((await db.execute(stmt)).scalars().all())
```

### carrot-api: service.py 추가

```python
async def send_message(
    db: AsyncSession,
    room_id: str,
    sender_email: str,
    post_id: int,
    message: str,
) -> MessageResponse:
    existing = await repository.get_room_context(db, room_id)
    if existing:
        seller_email = existing.seller_email
        buyer_email = existing.buyer_email
    else:
        # 첫 메시지 — post에서 seller 추출, sender가 buyer
        post = await posts_repository.get_post_by_id(db, post_id)
        if post is None:
            raise AppException(code="POST_NOT_FOUND", detail="게시글을 찾을 수 없습니다.", status_code=404)
        seller_email = post.seller_email
        if sender_email == seller_email:
            raise AppException(code="SELF_CHAT_FORBIDDEN", detail="본인 게시글에는 채팅할 수 없습니다.", status_code=403)
        buyer_email = sender_email

    if sender_email not in (seller_email, buyer_email):
        raise AppException(code="FORBIDDEN", detail="채팅방 참여자가 아닙니다.", status_code=403)

    msg = await repository.create_message(db, room_id, seller_email, buyer_email, post_id, message)
    return MessageResponse.model_validate(msg)


async def get_chat_messages(
    db: AsyncSession,
    room_id: str,
    sender_email: str,
    after_id: int | None = None,
) -> list[MessageResponse]:
    existing = await repository.get_room_context(db, room_id)
    if existing and sender_email not in (existing.seller_email, existing.buyer_email):
        raise AppException(code="FORBIDDEN", detail="채팅방 참여자가 아닙니다.", status_code=403)
    messages = await repository.get_messages(db, room_id, after_id)
    return [MessageResponse.model_validate(m) for m in messages]
```

    enabled: !!roomId,

  useEffect(() => {
    if (serverMessages.length > 0) {
      const newLastId = serverMessages[serverMessages.length - 1].id
      if (!lastIdRef.current || newLastId > lastIdRef.current) {
        lastIdRef.current = newLastId
        // 확인된 낙관적 메시지 제거
        setOptimisticMessages(prev =>

    const text = input.trim()
    const tempId = Date.now()
    setInput('')
    setSending(true)

Future<void> _loadMessages() async {
  final client = ref.read(apiClientProvider);
  final repo = ChatsRepository(client);
  final result = await repo.getMessages(widget.roomId);
  if (mounted) setState(() {
    _messages = result;
    if (result.isNotEmpty) _lastMessageId = result.last['id'] as int?;

Future<void> _pollNewMessages() async {
  if (!mounted) return;
  final client = ref.read(apiClientProvider);
  final repo = ChatsRepository(client);
  final newMsgs = await repo.getMessages(widget.roomId, afterId: _lastMessageId);
  if (newMsgs.isNotEmpty && mounted) {

  final text = _controller.text.trim();
  if (text.isEmpty || _sending) return;
  _controller.clear();
  setState(() => _sending = true);
  final tempId = DateTime.now().millisecondsSinceEpoch;
  setState(() => _optimisticMessages.add(_OptimisticMessage(tempId: tempId, message: text)));
  try {
    final client = ref.read(apiClientProvider);
    final repo = ChatsRepository(client);
    await repo.sendMessage(widget.roomId, text, widget.postId);
    // 폴링이 확인 후 제거
  } catch (_) {
    setState(() {
      final idx = _optimisticMessages.indexWhere((m) => m.tempId == tempId);
      if (idx != -1) {
        _optimisticMessages[idx].pending = false;
        _optimisticMessages[idx].error = true;
      }
    });
  } finally {
    if (mounted) setState(() => _sending = false);
  }
}
