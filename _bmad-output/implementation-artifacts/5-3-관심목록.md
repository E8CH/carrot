# Story 5.3: 관심목록

Status: done

## Story

As a 회원,
I want to see all posts I've liked,
so that I can revisit items I was interested in.

## Acceptance Criteria

1. 로그인한 회원이 `GET /api/v1/users/me/likes`를 호출하면 내가 찜한 게시글 목록이 반환된다
2. 삭제된 게시글은 FK CASCADE로 `likes`에서 자동 제거되어 목록에 노출되지 않는다 (DB 수준 보장 — 코드 추가 불필요)
3. 각 항목은 `PostListItem` 형식 (id, title, price, is_free, status, thumbnail, chat_count, like_count, created_at)
4. 목록은 `likes.created_at` 내림차순 정렬 (최근 찜한 것 먼저)
5. Next.js 나의 당근 페이지(`/my`)에 관심목록 섹션이 추가된다 — 찜한 게시글이 PostCard 형식으로 표시
6. Flutter 나의당근 탭에도 동일한 관심목록 섹션이 추가된다
7. 빈 목록이면 "관심목록이 없어요." 안내 표시

### Task 1: repository.py get_liked_posts

```python
async def get_liked_posts(db: AsyncSession, user_email: str) -> tuple[list, int]:
    like_count_sq = (
        select(func.count(Like.id))
        .where(Like.post_id == Post.id)
        .correlate(Post)
        .scalar_subquery()
    )
    chat_count_sq = (
        select(func.count(ChatMessage.id))
        .where(ChatMessage.post_id == Post.id)
        .correlate(Post)
        .scalar_subquery()
    )

    stmt = (
        select(Post, like_count_sq.label("like_count"), chat_count_sq.label("chat_count"))
        .join(Like, Like.post_id == Post.id)
        .where(
            Like.user_email == user_email,
            Post.is_draft == False,  # noqa: E712
        )
        .order_by(Like.created_at.desc())
    )
    rows = (await db.execute(stmt)).all()
    return rows, len(rows)
```

**중요**: `Like.created_at.desc()` 정렬 — 가장 최근에 찜한 게시글이 먼저 표시됨.

### Task 2: service.py get_liked_posts

`MyPostsResponse` 재사용 가능 — 이미 `items: list[PostListItem], total: int` 구조를 가짐.

```python
async def get_liked_posts(db: AsyncSession, user_email: str) -> MyPostsResponse:
    rows, total = await repository.get_liked_posts(db, user_email)
    items: list[PostListItem] = []
    for post, like_count, chat_count in rows:
        thumbnail = post.photos[0] if post.photos else None
        items.append(
            PostListItem(
                id=post.id,
                title=post.title,
                price=post.price,
                is_free=post.is_free,
                status=post.status,
                thumbnail=thumbnail,
                chat_count=chat_count,
                like_count=like_count,
                created_at=post.created_at,
            )
        )
    return MyPostsResponse(items=items, total=total)
```

### Task 7-8: Flutter 구현 가이드

**`myLikesProvider`:**

```dart
final myLikesProvider = FutureProvider.autoDispose<Map<String, dynamic>>((ref) async {
  final client = ref.read(apiClientProvider);
  final repo = MyRepository(client);
  return await repo.getMyLikes();

```

**Flutter PostCard 재사용:**
PostCard는 `Map<String, dynamic> post`를 받음. API 응답의 items 각 요소가 그대로 사용 가능:
- `post['thumbnail']`, `post['title']`, `post['price']`, `post['status']`, etc.

```dart
PostCard(
  post: item as Map<String, dynamic>,
  onTap: () => Navigator.of(context).push(MaterialPageRoute(
    builder: (_) => PostDetailScreen(postId: (item as Map<String, dynamic>)['id'] as int),
  )),
)
```
