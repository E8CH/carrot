# Story 5.2: 구매내역

Status: done

## Story

As a 구매자,
I want to see a list of trades where I was confirmed as the buyer,
so that I can review my purchase history.

## Acceptance Criteria

1. 로그인한 회원이 `GET /api/v1/users/me/purchases`를 호출하면 `buyer_email = me`인 거래완료 게시글 목록이 반환된다
2. 각 항목에 `id, title, thumbnail(photos[0]), price, is_free, updated_at`이 포함된다 (`updated_at` = 거래완료 날짜)
3. 목록은 `updated_at` 내림차순 정렬 (최신 거래 먼저)
4. Next.js 나의 당근 페이지(`/my`)에 구매내역 섹션이 추가된다 — 게시글 제목·대표 사진·가격·거래완료 날짜 표시
5. Flutter 나의당근 탭에도 동일한 구매내역 섹션이 추가된다
6. 빈 목록이면 "구매내역이 없어요." 안내 표시

### Task 1: schemas.py PurchaseItem

    model_config = ConfigDict(from_attributes=True)

    id: int
    title: str
    thumbnail: str | None
    price: int | None
    is_free: bool
    updated_at: datetime


class PurchasesResponse(BaseModel):

`thumbnail`은 ORM 객체에 없는 파생 필드이므로 `from_attributes=True` 사용 불가 — service.py에서 수동 매핑 필요 (5-1의 PostListItem과 동일 패턴).

### Task 2: repository.py get_my_purchases

```python
async def get_my_purchases(db: AsyncSession, buyer_email: str) -> tuple[list[Post], int]:
    stmt = (
        select(Post)
        .where(
            Post.buyer_email == buyer_email,
            Post.status == '거래완료',
            Post.is_draft == False,  # noqa: E712
        )
        .order_by(Post.updated_at.desc())
    )
    rows = (await db.execute(stmt)).scalars().all()
    return list(rows), len(rows)
```

`get_my_posts`와 달리 like_count/chat_count 서브쿼리 없음 — 구매내역에는 불필요.

### Task 3: service.py get_my_purchases

```python
async def get_my_purchases(db: AsyncSession, buyer_email: str) -> PurchasesResponse:
    posts, total = await repository.get_my_purchases(db, buyer_email)
    items = [
        PurchaseItem(
            id=post.id,
            title=post.title,
            thumbnail=post.photos[0] if post.photos else None,
            price=post.price,
            is_free=post.is_free,
            updated_at=post.updated_at,
        )
        for post in posts
    ]
    return PurchasesResponse(items=items, total=total)
```

@users_router.get("/me/purchases", response_model=PurchasesResponse)
async def get_my_purchases(
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
) -> PurchasesResponse:
    email = current_user.get("sub")

  final date = DateTime.tryParse(isoString)?.toLocal();

}
