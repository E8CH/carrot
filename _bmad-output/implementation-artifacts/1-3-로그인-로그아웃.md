# Story 1.3: 로그인 & 로그아웃

Status: review

## Story

As a 가입된 회원,
I want to log in with my email and password and log out when done,
so that I can securely access my account and protect it when I'm finished.

## Acceptance Criteria

1. 활성 계정의 올바른 자격증명으로 `POST /api/v1/auth/login`을 호출하면 JWT가 반환된다
2. 잘못된 자격증명으로 로그인 시도하면 `{"detail": "이메일 또는 비밀번호가 올바르지 않습니다.", "code": "INVALID_CREDENTIALS"}` (401) 에러가 반환된다
3. 비활성화된 계정으로 로그인 시도하면 `{"detail": "비활성화된 계정입니다.", "code": "ACCOUNT_INACTIVE"}` (403) 에러가 반환된다
4. Next.js `/auth/login` 페이지에서 폼 제출 성공 시 JWT가 `localStorage.token`에 저장되고 홈 피드(`/`)로 이동한다
5. Next.js 폼 제출 실패 시 서버 에러 메시지가 인라인으로 표시된다
6. Next.js에서 로그아웃 후 인증 필요 페이지 접근 시 `/auth/login`으로 리다이렉트된다 (axios 인터셉터가 처리)
7. Flutter 로그인 성공 시 JWT가 저장되고 NavigationBar 홈 탭으로 이동한다
8. Flutter 로그아웃 탭 시 JWT가 삭제되고 로그인 화면으로 이동한다

### carrot-api: login service 패턴

```python
# app/features/users/service.py 추가
from app.core.security import verify_password

async def login(db: AsyncSession, request: LoginRequest) -> AuthResponse:
    user = await repository.get_user_by_email(db, request.email)
    if not user or not verify_password(request.password, user.hashed_password):
        raise AppException(
            code="INVALID_CREDENTIALS",
            detail="이메일 또는 비밀번호가 올바르지 않습니다.",
            status_code=401,
        )
    if not user.is_active:
        raise AppException(
            code="ACCOUNT_INACTIVE",
            detail="비활성화된 계정입니다.",
            status_code=403,
        )
    token = create_access_token({"sub": user.email, "role": user.role})
    return AuthResponse(
        access_token=token,
        token_type="bearer",
        user=UserInfo.model_validate(user),
    )
```

> ⚠️ **보안**: 사용자 없음과 비밀번호 불일치를 같은 에러로 통일(INVALID_CREDENTIALS). 사용자 존재 여부를 노출하지 않음.

### 아키텍처 강제 규칙

- INVALID_CREDENTIALS: 사용자 없음 + 비밀번호 불일치 모두 동일 응답 (보안)
- status_code: 로그인 성공 200, 잘못된 자격증명 401, 비활성 403
- JWT payload: `{"sub": email, "role": role}` — Story 1.2와 동일
