# Story 1.2: 회원가입

Status: review

## Story

As a 신규 사용자,
I want to create an account with email, password, address, and phone number,
so that I can access all features of the carrot service.

## Acceptance Criteria

1. 유효한 이메일·비밀번호(8자 이상)·주소·연락처로 `POST /api/v1/auth/register`를 호출하면 비밀번호가 bcrypt로 해시되어 DB에 저장되고 JWT가 반환된다
2. 응답에 `role: user`, `is_active: true`, `manner_temp: 36.5`로 초기화된 사용자 정보가 포함된다
3. 이미 가입된 이메일로 가입 시도하면 `{"detail": "이미 사용 중인 이메일입니다.", "code": "EMAIL_ALREADY_EXISTS"}` 에러가 반환된다
4. 비밀번호가 8자 미만이면 `{"detail": "비밀번호는 8자 이상이어야 합니다.", "code": "PASSWORD_TOO_SHORT"}` 에러가 반환된다
5. Next.js `/auth/register` 페이지에서 폼 제출 성공 시 JWT가 `localStorage.token`에 저장되고 홈 피드(`/`)로 이동한다
6. Next.js 폼 제출 실패 시 서버 에러 메시지가 인라인으로 표시된다
7. Flutter 회원가입 화면에서 폼 제출 성공 시 JWT가 저장되고 NavigationBar 홈 탭으로 이동한다
8. Flutter에서 토큰 저장 후 Riverpod `tokenProvider`가 갱신되어 이후 모든 API 호출에 자동으로 Authorization 헤더가 주입된다

### carrot-api: FastAPI 도메인 패턴 (필수 준수)

```
app/features/users/
  router.py     ← HTTP만 (request/response, status code)
  service.py    ← 비즈니스 로직 (중복 검증, 비밀번호 해시, JWT 발급)
  repository.py ← DB 쿼리만 (SELECT, INSERT)
  schemas.py    ← Pydantic 요청/응답 모델
  models.py     ← SQLAlchemy (이미 존재, 수정 금지)
```

**router.py 패턴:**
```python
from fastapi import APIRouter, Depends
from sqlalchemy.ext.asyncio import AsyncSession
from app.core.database import get_db
from app.features.users.schemas import RegisterRequest, AuthResponse
from app.features.users import service

router = APIRouter()

@router.post("/register", response_model=AuthResponse, status_code=201)
async def register(request: RegisterRequest, db: AsyncSession = Depends(get_db)):
    return await service.register(db, request)
```

**service.py 패턴:**
```python
from sqlalchemy.ext.asyncio import AsyncSession
from app.core.security import hash_password, create_access_token
from app.shared.exceptions import AppException
from app.features.users import repository
from app.features.users.schemas import RegisterRequest, AuthResponse, UserInfo

async def register(db: AsyncSession, request: RegisterRequest) -> AuthResponse:
    existing = await repository.get_user_by_email(db, request.email)
    if existing:
        raise AppException(
            code="EMAIL_ALREADY_EXISTS",
            detail="이미 사용 중인 이메일입니다.",
            status_code=409,
        )
    hashed = hash_password(request.password)
    user = await repository.create_user(
        db, email=request.email, hashed_password=hashed,
        address=request.address, phone=request.phone,
    )
    token = create_access_token({"sub": user.email, "role": user.role})
    return AuthResponse(
        access_token=token,
        token_type="bearer",
        user=UserInfo.model_validate(user),
    )
```

**repository.py 패턴:**
```python
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from app.features.users.models import User

async def get_user_by_email(db: AsyncSession, email: str) -> User | None:
    result = await db.execute(select(User).where(User.email == email))
    return result.scalar_one_or_none()

async def create_user(db: AsyncSession, *, email: str, hashed_password: str,
                      address: str, phone: str) -> User:
    user = User(email=email, hashed_password=hashed_password,
                address=address, phone=phone)
    db.add(user)
    await db.commit()
    await db.refresh(user)
    return user
```

**schemas.py 패턴:**
```python
from datetime import datetime
from pydantic import BaseModel, EmailStr, Field, ConfigDict

class RegisterRequest(BaseModel):
    email: EmailStr
    password: str = Field(min_length=8)
    address: str = Field(min_length=1)
    phone: str = Field(min_length=1)

class UserInfo(BaseModel):
    model_config = ConfigDict(from_attributes=True)
    id: int
    email: str
    address: str
    phone: str
    role: str
    manner_temp: float
    created_at: datetime

class AuthResponse(BaseModel):
    access_token: str
    token_type: str = "bearer"
    user: UserInfo
```

> ⚠️ Pydantic v2 주의: `from_orm=True` 대신 `ConfigDict(from_attributes=True)`. `model_validate(obj)` 사용.

**페이지 구조:**
```typescript
// src/app/auth/register/page.tsx
'use client'
import { useState } from 'react'
import { useRouter } from 'next/navigation'
import apiClient from '@/lib/api/axios'

export default function RegisterPage() {
  const router = useRouter()
  const [form, setForm] = useState({ email: '', password: '', address: '', phone: '' })
  const [error, setError] = useState('')
  const [loading, setLoading] = useState(false)

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()
    setLoading(true)
    setError('')
    try {
      const { data } = await apiClient.post('/api/v1/auth/register', form)
      localStorage.setItem('token', data.access_token)
      router.push('/')
    } catch (err: any) {
      setError(err.response?.data?.detail || '회원가입에 실패했습니다.')
    } finally {
      setLoading(false)
    }
  }

  return (
    // shadcn/ui Card + Input + Button + Label 사용
    // 에러: <p className="text-red-500 text-sm">{error}</p>
  )
}
```

### carrot-mobile: Riverpod 토큰 관리 (CR#1 해결)

**핵심 설계 원칙:**
- `tokenProvider`: 메모리의 현재 토큰 (null이면 비로그인)
- `apiClientProvider`: tokenProvider를 watch → 토큰 변경 시 자동으로 새 ApiClient 반환
- SharedPreferences: 앱 재시작 시 토큰 복원

```dart
// lib/core/providers/token_provider.dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:shared_preferences/shared_preferences.dart';

final tokenProvider = StateProvider<String?>((ref) => null);

// 앱 시작 시 저장된 토큰 복원
final tokenInitializerProvider = FutureProvider<void>((ref) async {
  final prefs = await SharedPreferences.getInstance();
  final token = prefs.getString('token');
  if (token != null) {
    ref.read(tokenProvider.notifier).state = token;
  }
});
```

```dart
// lib/core/providers/api_client_provider.dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../api/api_client.dart';
import 'token_provider.dart';

final apiClientProvider = Provider<ApiClient>((ref) {
  final token = ref.watch(tokenProvider);
  return ApiClient(token: token);
});
```

**토큰 저장 (로그인/회원가입 성공 후):**
```dart
// register_screen.dart 내부
final data = await authRepo.register(
  ref.read(apiClientProvider),   // 현재 ApiClient (토큰 없어도 register는 가능)
  email: email, password: password, address: address, phone: phone,
);
final token = data['access_token'] as String;
// 1. Riverpod 상태 갱신 → apiClientProvider 자동 재생성
ref.read(tokenProvider.notifier).state = token;
// 2. 영구 저장
final prefs = await SharedPreferences.getInstance();
await prefs.setString('token', token);
// 3. 홈으로 이동
if (mounted) Navigator.pushAndRemoveUntil(
  context,
  MaterialPageRoute(builder: (_) => const MainScaffold()),
  (route) => false,
);
```

**main.dart 수정 (토큰 초기화):**
```dart
class CarrotApp extends ConsumerWidget {  // StatelessWidget → ConsumerWidget
  const CarrotApp({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // 앱 시작 시 토큰 복원 (로딩 중엔 스플래시 표시 가능)
    ref.watch(tokenInitializerProvider);
    return MaterialApp(
      title: 'carrot',
      theme: AppTheme.light,
```
