# Story 1.4: 회원 프로필 조회

Status: review

## Story

As a 로그인한 회원,
I want to view my profile including email, address, phone number, and manner temperature,
so that I can confirm my account information and current trust score.

## Acceptance Criteria

1. 로그인한 회원이 `GET /api/v1/users/me`를 호출하면 `{email, address, phone, role, manner_temp, created_at}` 형식의 데이터가 반환된다
2. `manner_temp`는 소수점 1자리로 반환된다
3. JWT 없이 `GET /api/v1/users/me`를 호출하면 401이 반환된다
4. Next.js 나의 당근 탭(`/my`)에서 페이지 로드 시 회원의 이메일·주소·연락처·매너온도가 표시된다
5. Next.js에서 매너온도는 MannerTempWidget 컴포넌트로 렌더링된다
6. Flutter 나의당근 탭에서 탭 진입 시 동일한 프로필 정보와 MannerTempWidget이 표시된다
7. MainScaffold 나의당근 탭의 Placeholder가 실제 프로필 화면으로 교체된다

### carrot-api: 라우터 분리 패턴

현재 `app/api/v1/router.py`에는 auth 라우터만 있음.  
이번 스토리에서 users 라우터 추가:

```python
# app/features/users/router.py에 추가
@router.get("/me", response_model=UserInfo)
async def get_me(
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
) -> UserInfo:
    user = await repository.get_user_by_email(db, current_user["sub"])
    if not user:
        raise AppException(code="USER_NOT_FOUND", detail="사용자를 찾을 수 없습니다.", status_code=404)
    user.manner_temp = round(user.manner_temp, 1)
    return UserInfo.model_validate(user)
```

```python
# app/api/v1/router.py
from app.features.users.router import router as auth_router, me_router
# 또는 하나의 router 파일에서 prefix 분리:
router.include_router(users_router, prefix="/auth", tags=["auth"])
router.include_router(users_router, prefix="/users", tags=["users"])
```

> 권장: auth 엔드포인트(register/login)와 users 엔드포인트(me)를 같은 router.py에서 다른 APIRouter 인스턴스로 분리하거나, v1/router.py에서 prefix로 구분.

### carrot-web: MannerTempWidget

```typescript
// src/components/common/MannerTempWidget.tsx
interface Props { temp: number }

function getTempColor(temp: number): string {
  if (temp <= 30) return '#3B82F6'      // 파랑
  if (temp <= 50) return '#FF7E36'      // 오렌지
  return '#EF4444'                       // 빨강
}

export function MannerTempWidget({ temp }: Props) {
  return (
    <span className="inline-flex items-center gap-1 font-semibold" style={{ color: getTempColor(temp) }}>
      🥕 {temp.toFixed(1)}℃
    </span>
  )
}
```

### carrot-mobile: MannerTempWidget (Flutter)

```dart
class MannerTempWidget extends StatelessWidget {
  final double temp;
  const MannerTempWidget({super.key, required this.temp});

  Color get color {
    if (temp <= 30) return AppColors.mannerCold;
    if (temp <= 50) return AppColors.mannerWarm;
    return AppColors.mannerHot;
  }

  @override
  Widget build(BuildContext context) {
    return Text(
      '🥕 ${temp.toStringAsFixed(1)}℃',
      style: TextStyle(color: color, fontWeight: FontWeight.bold, fontSize: 18),
    );
  }
}
```

### carrot-mobile: MyScreen FutureProvider 패턴

```dart
final myProfileProvider = FutureProvider.autoDispose<Map<String, dynamic>>((ref) async {
  final client = ref.read(apiClientProvider);
  final repo = MyRepository(client);
  return await repo.getMe();
});

class MyScreen extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final profile = ref.watch(myProfileProvider);
    return profile.when(
      data: (data) => _ProfileContent(data: data, onLogout: () async {
        await clearToken(ref);
        // navigation 처리
      }),
      loading: () => const Center(child: CircularProgressIndicator()),
      error: (e, _) => Center(child: Text('프로필을 불러올 수 없습니다.')),
    );
  }
}
```
