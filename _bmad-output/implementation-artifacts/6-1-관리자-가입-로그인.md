# Story 6.1: 관리자 가입 & 로그인

Status: done

## Story

As a 관리자,
I want to register and log in through the dedicated admin web,
so that I can access the admin dashboard to manage the service.

## Acceptance Criteria

1. `POST /api/v1/admin/register` — 이메일+비밀번호로 `role: admin` 계정 생성, JWT 반환
2. `POST /api/v1/admin/login` — 이메일+비밀번호로 로그인. `role: admin` 아닌 계정이면 `ADMIN_REQUIRED` 403 에러 반환
3. carrot-admin `/auth/login` 페이지에서 로그인 성공 시 JWT를 `admin_token`으로 저장, 대시보드(`/dashboard`)로 이동
4. 대시보드에 사이드바 메뉴 3개 표시: 회원 관리 / 거래 관리 / 채팅 관리
5. carrot-admin의 인증 필요 페이지에서 토큰 없으면 `/auth/login`으로 리다이렉트
6. 로그인 페이지: 이메일/비밀번호 폼, 오류 시 인라인 에러 표시

## Dev Notes

### Task 1: admin/router.py 구현

**register endpoint:**
```python
from app.core.security import create_access_token, hash_password, verify_password
from app.features.users import repository as users_repo
from app.features.users.schemas import AuthResponse, UserInfo
from app.features.users.models import User

@router.post("/register", response_model=AuthResponse, status_code=201)
async def admin_register(request: AdminRegisterRequest, db: AsyncSession = Depends(get_db)):
    existing = await users_repo.get_user_by_email(db, request.email)
    if existing:
        raise AppException(code="EMAIL_ALREADY_EXISTS", detail="이미 사용 중인 이메일입니다.", status_code=409)
    
    hashed = hash_password(request.password)
    user = User(
        email=request.email,
        hashed_password=hashed,
        address='',    # 관리자는 address/phone 불필요, 빈 문자열로 처리
        phone='',
        role='admin',
    )
    db.add(user)
    try:
        await db.commit()
        await db.refresh(user)
    except IntegrityError:
        await db.rollback()
        raise AppException(code="EMAIL_ALREADY_EXISTS", detail="이미 사용 중인 이메일입니다.", status_code=409)
    
    token = create_access_token({"sub": user.email, "role": user.role})
    return AuthResponse(access_token=token, token_type="bearer", user=UserInfo.model_validate(user))
```

**User 모델 주의**: `address: String(500) nullable=False`, `phone: String(20) nullable=False` — 빈 문자열 `''`로 처리.

**login endpoint:**
```python
@router.post("/login", response_model=AuthResponse)
async def admin_login(request: AdminLoginRequest, db: AsyncSession = Depends(get_db)):
    user = await users_repo.get_user_by_email(db, request.email)
    password_ok = user is not None and verify_password(request.password, user.hashed_password)
    if not password_ok:
        raise AppException(code="INVALID_CREDENTIALS", detail="이메일 또는 비밀번호가 올바르지 않습니다.", status_code=401)
    if not user.is_active:
        raise AppException(code="ACCOUNT_INACTIVE", detail="비활성화된 계정입니다.", status_code=403)
    if user.role != 'admin':
        raise AppException(code="ADMIN_REQUIRED", detail="관리자 권한이 없습니다.", status_code=403)
    
    token = create_access_token({"sub": user.email, "role": user.role})
    return AuthResponse(access_token=token, token_type="bearer", user=UserInfo.model_validate(user))
```

**users/service.login 패턴 재사용** — timing attack 방지를 위해 verify_password를 항상 실행한 뒤 role 체크.

### Task 4: auth.ts API

```typescript
import apiClient from './axios'

export interface AdminUser {
  id: number
  email: string
  role: string
  manner_temp: number
  created_at: string
}

export interface AdminAuthResponse {
  access_token: string
  token_type: string
  user: AdminUser
}

export const adminAuthApi = {
  login: (email: string, password: string): Promise<AdminAuthResponse> =>
    apiClient.post<AdminAuthResponse>('/api/v1/admin/login', { email, password }).then((r) => r.data),

  register: (email: string, password: string): Promise<AdminAuthResponse> =>
    apiClient.post<AdminAuthResponse>('/api/v1/admin/register', { email, password }).then((r) => r.data),
}
```

**주의**: 기존 `axios.ts`는 `admin_token` 키로 JWT를 주입. 로그인 성공 후 `localStorage.setItem('admin_token', token)` 필수.

### Task 7: (admin)/layout.tsx — 클라이언트 측 인증 가드

Next.js middleware에서 localStorage 접근 불가 → `layout.tsx`에서 useEffect로 처리:

```tsx
'use client'
import { useEffect } from 'react'
import { useRouter } from 'next/navigation'
import AdminSidebar from '@/components/layout/AdminSidebar'

export default function AdminLayout({ children }: { children: React.ReactNode }) {
  const router = useRouter()
  useEffect(() => {
    if (!localStorage.getItem('admin_token')) {
      router.replace('/auth/login')
    }
  }, [router])

  return (
    <div className="flex h-full min-h-screen">
      <AdminSidebar />
      <main className="flex-1 p-6 bg-gray-50">{children}</main>
    </div>
  )
}
```

### Task 9: middleware.ts — 최소 구성

Next.js middleware에서 localStorage 접근 불가. 쿠키 기반 인증이 아니므로 middleware는 단순하게:
- 토큰은 localStorage에 있어서 middleware에서 직접 검증 불가
- 대신 layout.tsx에서 클라이언트 측 리다이렉트로 처리
- middleware.ts는 빈 파일 또는 matcher 없이 생성 가능

실제로 Next.js middleware에서 JWT를 검증하려면 쿠키에 저장해야 합니다. 현재 구현(localStorage)에서는 layout의 useEffect가 인증 가드 역할을 담당합니다.

```typescript
// middleware.ts - 최소 구성 (실제 가드는 layout에서 처리)
export function middleware() {}
export const config = { matcher: [] }
```
