# Story 2.1: 홈 피드 (게시글 목록 조회)

Status: review

## Story

As a 사용자 (비로그인 포함),
I want to browse a list of posts sorted by newest first,
so that I can discover items available for sale.

## Acceptance Criteria

1. `GET /api/v1/posts?page=1&size=20`을 호출하면 `{items, total, page, size}` 형식으로 최신순 게시글 목록이 반환된다
2. 각 항목에 `id, title, price, is_free, status, photos[0], chat_count, like_count, created_at`이 포함된다
3. 거래완료 게시글도 목록에 포함된다 (상태 필터 없음)
4. 비로그인 포함 모든 사용자가 호출 가능하다 (인증 불필요)
5. Next.js 홈 피드(`/`)에서 PostCard 목록이 렌더링된다 (좌 썸네일 100×100px + 우 제목·가격·StatusBadge·채팅수·관심수·경과시간)
6. 스크롤 하단 도달 시 다음 20개를 자동 로드한다 (무한 스크롤 — TanStack Query `useInfiniteQuery`)
7. Flutter 홈 탭에서 PostCard 위젯 ListView가 렌더링되고 무한 스크롤이 동작한다

### carrot-api: posts repository — subquery 패턴

```python
from sqlalchemy import select, func
from app.features.posts.models import Post, Like
from app.features.chats.models import ChatMessage

async def get_posts(db: AsyncSession, page: int, size: int):
    like_count = (
        select(func.count(Like.id))
        .where(Like.post_id == Post.id)
        .correlate(Post)
        .scalar_subquery()
    )
    chat_count = (
        select(func.count(ChatMessage.id))
        .where(ChatMessage.post_id == Post.id)
        .correlate(Post)
        .scalar_subquery()
    )
    stmt = (
        select(Post, like_count.label("like_count"), chat_count.label("chat_count"))
        .where(Post.is_draft == False)
        .order_by(Post.created_at.desc())
        .offset((page - 1) * size)
        .limit(size)
    )
    rows = (await db.execute(stmt)).all()

    count_stmt = select(func.count(Post.id)).where(Post.is_draft == False)
    total = (await db.execute(count_stmt)).scalar_one()

    return rows, total
```

### carrot-web: 경과 시간 계산

```typescript
function timeAgo(date: string): string {
  const diff = Date.now() - new Date(date).getTime()
  const mins = Math.floor(diff / 60_000)
  if (mins < 1) return '방금 전'
  if (mins < 60) return `${mins}분 전`
  const hours = Math.floor(mins / 60)
  if (hours < 24) return `${hours}시간 전`
  return `${Math.floor(hours / 24)}일 전`
}
```

### carrot-web: 무한 스크롤 패턴

```typescript
// useInfiniteQuery (TanStack Query v5)
const { data, fetchNextPage, hasNextPage, isFetchingNextPage } = useInfiniteQuery({
  queryKey: ['posts'],
  queryFn: ({ pageParam }) => postsApi.getPosts(pageParam, 20),
  initialPageParam: 1,
  getNextPageParam: (lastPage, _, lastPageParam) =>
    lastPage.items.length === 20 ? lastPageParam + 1 : undefined,
})

// IntersectionObserver로 하단 감지
const bottomRef = useRef<HTMLDivElement>(null)
useEffect(() => {
  const observer = new IntersectionObserver(([entry]) => {
    if (entry.isIntersecting && hasNextPage) fetchNextPage()
  })
  if (bottomRef.current) observer.observe(bottomRef.current)
  return () => observer.disconnect()
}, [hasNextPage, fetchNextPage])
```

### carrot-mobile: 무한 스크롤 패턴 (ScrollController)

```dart
// FeedScreen state
final _scrollController = ScrollController();
int _page = 1;
List<Map<String, dynamic>> _posts = [];
bool _loading = false;
bool _hasMore = true;

@override
void initState() {
  super.initState();
  _scrollController.addListener(_onScroll);
  _loadPosts();
}

void _onScroll() {
  if (_scrollController.position.pixels >=
      _scrollController.position.maxScrollExtent - 200 &&
      !_loading && _hasMore) {
    _loadPosts();
  }
}
```
