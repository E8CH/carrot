# Story 3.4: 미읽음 배지

Status: done

## Story

As a 로그인한 회원,
I want to see a badge on the chat tab showing how many chat rooms have unread messages,
So that I never miss a new message.

## Acceptance Criteria

1. `GET /api/v1/chats/unread-count`를 호출하면 미읽음 채팅방 수(`count`)가 반환된다 (개별 메시지 수가 아닌 채팅방 수 기준)
2. 클라이언트가 채팅방 밖에 있을 때 2500ms 폴링으로 미읽음 수가 갱신되어 Flutter 채팅 탭 배지(+N)가 업데이트된다
3. 채팅방 진입 시 `PATCH /api/v1/chats/{room_id}/read`를 호출하면 해당 채팅방의 상대방 메시지 모두 `is_read=True`로 업데이트된다
4. 미읽음 채팅방이 없으면 배지가 표시되지 않는다

### carrot-api: repository.py

```python
from sqlalchemy import distinct, update

async def get_unread_count(db: AsyncSession, user_email: str) -> int:
    stmt = select(func.count(distinct(ChatMessage.room_id))).where(
        or_(
            ChatMessage.seller_email == user_email,
            ChatMessage.buyer_email == user_email,
        ),
        ChatMessage.is_read == False,  # noqa: E712
        ChatMessage.sender_email != user_email,
    )
    return (await db.execute(stmt)).scalar_one()

async def mark_room_as_read(db: AsyncSession, room_id: str, user_email: str) -> None:
    stmt = (
        update(ChatMessage)
        .where(
            ChatMessage.room_id == room_id,
            or_(
                ChatMessage.seller_email == user_email,
                ChatMessage.buyer_email == user_email,
            ),
            ChatMessage.sender_email != user_email,
        )
        .values(is_read=True)
    )
    await db.execute(stmt)
    await db.commit()
```

**Import 추가**: `from sqlalchemy import distinct, update` (기존 `from sqlalchemy import func, or_, select`에 추가)

### carrot-api: router.py 라우터 순서 주의

`GET /unread-count`는 반드시 `GET /{room_id}/messages` 앞에 등록해야 함.
- 실제로는 path segment 수가 달라 충돌 없음: `/unread-count`(1개) vs `/{room_id}/messages`(2개)
- 그래도 가독성 위해 `GET /` 바로 다음에 등록

```python
@router.get("/unread-count", response_model=UnreadCountResponse)
async def get_unread_count(...):
    ...

@router.patch("/{room_id}/read", status_code=204)
async def mark_as_read(
    room_id: str,
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
) -> None:
    user_email = current_user.get("sub")
    if not user_email:
        raise AppException(...)
    await service.mark_room_as_read(db, room_id, user_email)
```

### carrot-mobile: main_scaffold.dart — ConsumerStatefulWidget + 배지 폴링

`StatefulWidget` → `ConsumerStatefulWidget` 변환:

```dart
class MainScaffold extends ConsumerStatefulWidget {
  const MainScaffold({super.key});
  @override
  ConsumerState<MainScaffold> createState() => _MainScaffoldState();
}

class _MainScaffoldState extends ConsumerState<MainScaffold> {
  int _selectedIndex = 0;
  int _unreadCount = 0;
  Timer? _unreadTimer;

  final List<Widget> _pages = const [
    FeedScreen(),
    ChatListScreen(),
    MyScreen(),
  ];

  @override
  void initState() {
    super.initState();
    _pollUnreadCount();
    _unreadTimer = Timer.periodic(
      const Duration(milliseconds: 2500),
      (_) => _pollUnreadCount(),
    );
  }

  @override
  void dispose() {
    _unreadTimer?.cancel();
    super.dispose();
  }

  Future<void> _pollUnreadCount() async {
    try {
      final client = ref.read(apiClientProvider);
      final repo = ChatsRepository(client);
      final result = await repo.getUnreadCount();
      final count = result['count'] as int? ?? 0;
      if (mounted) setState(() => _unreadCount = count);
    } catch (_) {}
  }
```
