# 거래 안전 수칙

carrot은 개인 간 직거래(대면 거래 또는 계좌이체)만 지원합니다. 안전한 거래를 위해 아래 수칙을 꼭 확인하세요.

---

## 직거래 시 주의사항

### 거래 장소 선택
- 카페, 편의점, 지하철역 등 **사람이 많은 공공장소**에서 만나는 것을 권장합니다.
- 상대방의 집이나 인적이 드문 장소는 피하세요.
- 야간 거래보다는 낮 시간대 거래를 권장합니다.

### 물품 확인
- 거래 전 반드시 물품을 **직접 확인**하세요.
- 전자제품은 실제 작동 여부를 확인하고 거래하세요.
- 게시글 사진과 실제 물품이 다를 경우 거래를 거부할 수 있습니다.

### 가격 협의
- 가격 협의는 채팅을 통해 미리 진행하세요.
- 만나서 갑자기 가격을 바꾸는 행위는 금지됩니다.

---

## 택배 거래 시 주의사항

carrot은 택배 거래를 공식 지원하지 않습니다. 직거래를 원칙으로 합니다.

만약 당사자 간 합의로 택배 거래를 진행할 경우:
- **선입금 요구에 주의**하세요. 판매자 계정에 상품 사진, 후기, 거래 이력 등을 반드시 확인하세요.
- 본인 인증이 되지 않은 계정과의 거래는 신중히 결정하세요.
- carrot은 택배 거래 중 발생한 분쟁에 대해 책임을 지지 않습니다.

---

## 사기 예방

### 의심스러운 거래 유형
다음과 같은 상황이라면 사기일 가능성이 있습니다:
- 시세보다 지나치게 저렴한 가격에 판매하는 경우
- 직거래를 거부하고 택배만 고집하는 경우
- 개인정보(주민등록번호, 계좌 비밀번호 등)를 요구하는 경우
- 외부 링크나 앱 설치를 유도하는 경우
- 입금 후 연락이 두절되는 경우

### 안전한 계좌이체
- 모르는 계좌로 선입금하는 것은 피하세요.
- 가능하면 직접 만나서 물건 확인 후 그 자리에서 이체하세요.
- 이체 확인증을 반드시 보관하세요.

---

## 신고 방법

사기 또는 불법 거래를 발견한 경우 다음 방법으로 신고할 수 있습니다:
1. 해당 게시글 또는 채팅방에서 **신고하기** 버튼을 누릅니다.
2. 신고 사유를 선택하고 내용을 입력합니다.
3. 운영팀이 확인 후 조치합니다.

---

## 계정 보안

- 비밀번호는 다른 서비스와 다르게 설정하세요.
- 본인 외 다른 사람에게 계정 정보를 알려주지 마세요.
- 로그인 후 자리를 비울 때는 반드시 로그아웃하세요.
- 계정이 도용된 것 같으면 즉시 비밀번호를 변경하고 운영팀에 문의하세요.
