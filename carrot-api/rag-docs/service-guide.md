# carrot 서비스 이용 가이드

## 회원가입 및 로그인

### 회원가입 방법
이메일, 비밀번호, 주소, 연락처를 입력하여 계정을 만들 수 있습니다.
- 이메일은 중복 사용이 불가하며, 가입 후 변경할 수 없습니다.
- 비밀번호는 최소 8자 이상이어야 합니다.
- 주소는 거래 지역을 표시하기 위한 텍스트 필드입니다. (위치 기반 필터링에 사용되지 않습니다)
- 가입 즉시 계정이 활성화되며, 이메일 인증은 필요하지 않습니다.

### 로그인 방법
가입한 이메일과 비밀번호로 로그인합니다. 로그인 후 JWT 인증 토큰이 발급되어 이후 서비스를 이용할 수 있습니다.

### 로그아웃
프로필 화면 또는 설정 메뉴에서 로그아웃할 수 있습니다. 로그아웃하면 인증 토큰이 삭제됩니다.

## 게시글 등록하기

### 게시글 작성 방법
1. 홈 피드 화면 하단의 **글쓰기(+)** 버튼을 누릅니다.
2. 사진을 1장 이상 업로드합니다. (최대 10장)
3. 제목과 설명을 입력합니다. (둘 다 필수)
4. 가격 유형을 선택합니다.
   - **판매하기**: 원하는 가격을 입력합니다.
   - **나눔하기**: 무료로 나눔합니다.
5. 거래 희망 장소를 텍스트로 입력합니다.
6. **작성 완료**를 누르면 게시글이 등록됩니다.

### 임시저장
작성 중 뒤로 가거나 앱을 닫으면 임시저장됩니다. 계정당 1개의 임시저장만 유지되며, 다음에 글쓰기를 시작하면 이어서 편집할 수 있습니다. 임시저장된 게시글은 목록에 노출되지 않습니다.

### 게시글 수정 및 삭제
본인이 등록한 게시글은 언제든지 수정하거나 삭제할 수 있습니다. 게시글 상세 화면에서 **수정/삭제** 버튼을 누릅니다. 삭제 시 연결된 채팅 내역도 함께 삭제됩니다.

---

## 게시글 탐색하기

### 홈 피드
로그인하지 않아도 전체 게시글 목록을 볼 수 있습니다. 목록에는 대표 사진, 제목, 가격, 거래 상태 배지, 채팅 수, 관심 수가 표시됩니다. 최신 게시글 순으로 정렬되며 20개씩 불러옵니다.

### 게시글 검색
홈 피드 상단의 검색창에 키워드를 입력하면 제목 또는 설명에 해당 키워드가 포함된 게시글을 찾을 수 있습니다.

### 찜(관심) 등록
로그인한 상태에서 게시글에 하트 버튼을 누르면 찜 목록에 추가됩니다. 다시 누르면 해제됩니다. 찜한 게시글은 **나의 당근 > 관심목록**에서 모아볼 수 있습니다.

---

## 채팅 및 거래하기

### 채팅 시작 방법
1. 마음에 드는 게시글의 상세 화면으로 이동합니다.
2. **채팅하기** 버튼을 누릅니다.
3. 1:1 채팅방이 생성되어 판매자와 대화할 수 있습니다.
- 같은 게시글에 이미 채팅방이 있으면 기존 채팅방으로 이동합니다.
- 본인 게시글에서는 채팅하기 버튼이 비활성화됩니다.

### 채팅 목록 확인
하단 탭의 **채팅** 메뉴에서 참여 중인 모든 채팅방을 확인할 수 있습니다. 새로운 메시지가 있으면 채팅 탭에 미읽음 배지(+N)가 표시됩니다.

### 거래 상태 변경
판매자는 채팅방 또는 게시글 상세에서 거래 상태를 변경할 수 있습니다.
- **판매중**: 기본 상태, 구매자를 찾고 있는 상태
- **예약중**: 특정 구매자와 거래를 진행 중인 상태
- **거래완료**: 거래가 완료된 상태. 거래완료로 변경 시 구매자를 선택해야 합니다.

거래완료 상태로 되돌리는 것은 불가합니다. 예약중 → 판매중으로 되돌리는 것은 가능합니다.

---

## 후기 및 매너온도

### 후기 작성
거래완료 후 판매자와 구매자 모두 상대방에게 후기를 작성할 수 있습니다.
- 긍정 또는 부정 중 하나를 선택합니다.
- 선택형 태그로 상세 평가를 남길 수 있습니다.
- 텍스트 후기는 선택 사항입니다.

### 매너온도
매너온도는 회원의 거래 신뢰도를 나타내는 지표로, 섭씨 온도 단위로 표시됩니다.
- 기본값은 **36.5℃**입니다.
- 긍정 후기를 받으면 **+1℃**, 부정 후기를 받으면 **-1℃** 변동합니다.
- 프로필 화면과 게시글 상세에서 확인할 수 있습니다.

---

## 나의 당근

**나의 당근** 탭에서 개인 활동 내역을 확인할 수 있습니다.
- **판매관리**: 내가 등록한 게시글 목록과 거래 상태
- **구매내역**: 거래완료된 구매 거래 목록
- **관심목록**: 찜한 게시글 목록
- **프로필**: 이메일, 주소, 연락처, 매너온도 조회
